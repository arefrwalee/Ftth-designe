# مصمم الدراسات الهوائية

أداة لتصميم دراسات شبكات FTTH الهوائية وحساب كمياتها وكلفتها لأي بلدة:
مباني + طرق + موقع المركز ← مسودة تصميم (سبلترات وكبلات وكلوجرات وأعمدة) ← مراجعة في QGIS ← BOQ وعرض سعر.

- `app/core`: الكود (Python).
- `app/standards`: المعايير الافتراضية (JSON) — تُجاوَز لكل دراسة عبر `overrides` في `study.json`.
- `app/templates`: قالب مشروع QGIS.
- بيانات الدراسات (gpkg وقوالب BOQ والأسعار) **لا تُرفع** إلى هذا المستودع وتبقى محلية (انظر `.gitignore`).
